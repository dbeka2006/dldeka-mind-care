# MindBridge — 감정 상태 기반 맞춤 행동 솔루션 웹 서비스

- **서비스 바로가기:** https://본인아이디.github.io/저장소이름/

## 1. 기획 의도 및 핵심 기능
사용자가 현재 느끼는 감정 유형(6종)과 강도(1~10점), 상황 메모를 입력하면 즉각 실행할 수 있는 행동 지침과 생각 전환 질문을 처방하는 단일 페이지 웹 애플리케이션입니다.

- **강도별 3단계 맞춤 처방 분기:**
  - `1~3점 (약함)`: 일상 루틴 유지 및 예방 팁
  - `4~7점 (중간)`: 호흡법·인지 전환 질문 등 집중 케어
  - `8~10점 (강함)`: 업무 중단 권고 경고 배너 출력 및 신체 긴장 완화 최우선 처방
- **상황 키워드 감지:** 메모에 `수면/피곤`, `오류/배포`, `사람/갈등` 등의 키워드 포함 시 상황별 맞춤 팁 추가 노출
- **데이터 보존:** 별도 서버 없이 브라우저 `localStorage`를 활용해 새로고침 후에도 최근 20건의 감정 히스토리 유지

## 2. QA 테스트 및 검증 내역
- [x] 감정 6종 버튼 클릭 시 선택 상태 전환 및 해당 감정 데이터 정상 매핑 확인
- [x] 강도 슬라이더 8점 이상 설정 시 상단 긴급 휴식 경고 배너 노출 여부 검증
- [x] 상황 메모 내 특정 키워드('오류', '피곤' 등) 입력 시 맞춤 팁 박스 동적 출력 확인
- [x] 브라우저 새로고침 후에도 최근 기록 리스트 유지 및 개별/전체 삭제 기능 정상 작동 확인
- [x] 모바일(iPad)·데스크톱 반응형 레이아웃 깨짐 여부 점검
